# 常用供应商与密钥配置

管理入口：`/admin/models`，默认进入快速配置。选择供应商、填写或沿用密钥、选择模型与文本审核方式，点击“保存并启用聊天”即可同时启用供应商、模型和默认聊天路由。操作会记录审计，确认后真实调用可能产生费用。高级供应商、模型、路由配置仍保留。

“读取可用模型”从已保存密钥对应的官方固定端点读取模型列表，减少手填过期 ID；不支持模型列表的供应商保留预设和自定义。模型是否可用于对话仍以供应商权限和连通测试为准。“测试已保存模型”需要确认真实 API 费用，返回连通耗时或安全的错误说明，不显示密钥。

点击“导入常用预设”，新增六家国内供应商与十五个对话模型，再填写变更原因发布。重复导入不会覆盖现有密钥、模型或路由。所有新增供应商与模型默认关闭。

## 密钥管理

API Key 保存时验证纯密钥格式；含中文、内部空白、Bearer 前缀或说明文字会被拒绝。已保存的异常密钥只显示“格式异常”状态，不回传原文，也不会自动猜测或改写密钥。需要管理员重新从供应商控制台复制纯密钥。

供应商编辑窗口提供官方密钥控制台链接、固定 API 地址、API Key 密码输入、启用开关和清除密钥选项。新密钥由管理员自行申请；本项目不包含真实供应商密钥。留空保持原密钥，发布后客户端仅看到是否已配置，不返回原文。后台使用 AES-256-GCM 加密入库，以 AI_CONFIG_ENCRYPTION_KEY 作为主密钥，需要独立备份；不要写入 Git、日志或 Notion。

密钥地区必须与固定地址一致。阿里百炼和豆包目前使用北京端点，不能混用境外密钥；智谱使用通用按量计费端点，不是 Coding Plan 专用端点。除既有 OpenAI 环境配置外，这些密钥从后台加密配置读取，不会自动读取同名供应商环境变量。

文字聊天运行模式与 APP_MODE（演示充值等）分离：AUTO 在启用聊天路由后使用真实模型；LIVE 强制真实调用，配置缺失或接口失败时报错，不返回演示文案；DEMO 才强制本地演示。快捷启用会设置 LIVE，无需改环境变量或重启。图片和语音组合仍受原有 APP_MODE 正式模式控制。

启用供应商、模型并配置主备路由后发布。文字聊天、图片提示词、语音对话回答均可选择这些对话模型。国内供应商本次只适配 CHAT，图片生成与语音识别/合成仍采用已有的对应能力适配器，不能把不兼容的原生图片或语音模型填成聊天模型。

## 文本审核选择

默认保持 OpenAI 专用内容审核。也可显式选择“所选聊天模型安全分类”：对用户输入和回复各追加一次独立分类请求，只有精确 ALLOW 才放行；BLOCK 拒绝，异常输出或请求失败关闭服务。输入拒绝时不扣费，输出拒绝退回聊天星币，供应商已产生的调用费用仍需支付。此模式不是关闭审核，但通用模型分类存在提示注入、误判和漏判风险，不等价于专用审核产品，不可据此宣称满足生产内容合规。十万日活上线前仍须引入专用审核、红队评测、人工复核与申诉机制。图片审核仍依赖原有 OpenAI 专用审核。

角色聊天默认关闭 DeepSeek、智谱与豆包的深度思考；Kimi K2.6 关闭思考，K3 使用 low 推理强度。现有单次请求 20 秒超时仍适用，超时可走已配置备用模型。

## 供应商错误诊断

错误识别优先读取供应商 JSON 错误码，不再将所有 HTTP 400 都当作模型参数错误。Arrearage 表示阿里账户欠费或计费异常；isv.OUT_OF_SERVICE 表示余额不足暂停服务；模型未开通、免费额度耗尽、密钥无效及内容安全拒绝有独立提示。仅允许白名单错误码映射到固定中文消息，原始供应商响应不传给客户端、不写调用记录；读取错误响应限制 8 KB。

已实测阿里接口返回 HTTP 400 / Arrearage，需由账户持有人检查 API Key 所属账号的费用与成本、余额及百炼计费状态；若未欠费，应核对所属账号并联系阿里客服。充值恢复可能有延迟，恢复后再做连通测试。应用不会代用户充值或通过修改模型参数绕过计费拒绝。文字聊天在扣费前失败不扣星币，扣费后失败按原有流程退回，并保留安全错误码用于诊断。

官方依据：[百炼错误码](https://help.aliyun.com/zh/model-studio/error-code#overdue-payment)。

## 发布与验证

无需数据库结构迁移。执行 npm test、npm run typecheck、npm run build 后重启服务。测试覆盖重复导入、默认关闭、密钥保留、能力校验、固定端点、Bearer 鉴权与供应商参数，以及 APP_MODE=demo 时已配置真实聊天不被演示逻辑覆盖、审核异常不扣费、显式演示和真实模式。真实接口、账户权限、付费额度与延迟需要管理员配置密钥后测试。模型集成测试完整备份并恢复加密配置，使用版本比较避免覆盖并发修改，不能用脱敏配置恢复真实密钥。
